# 漂岛奇航 · 晴帆岛可玩原型

网页 Three.js 原型，对应《漂岛奇航_游戏概念与美术资源清单》的核心循环。一局约 10–15 分钟。

```sh
npm install
npm run dev      # http://127.0.0.1:4173
npm run build    # 输出 dist/，可静态部署
```

## 玩法流程

1. 海滩捡漂流木、灌木采叶片、捡石块
2. 随身把叶片搓成绳子；在工作台做木弯刀、石斧、木板
3. 石斧砍棕榈（木材 + 叶片 + 椰子），做 4 块木板去码头修船壳
4. 东边潮汐神龛推动潮汐（或等 75 秒自动切换），退潮时沙洲露出
5. 走过沙洲到小岛遗迹，打败椰壳蟹，开宝箱拿罗盘碎片
6. 贝壳（退潮滩涂 / 蟹掉落）做补丁帆，竖桅杆，装罗盘，出航

## 生活与探索系统

- **测试模式**（标题页勾选，默认开）：所有工具、每样材料 99、随处制作不扣材料、宝箱无守卫
- **移动**：Shift 奔跑（耗体力）· 空格跳跃 · 空中再按空格展开滑翔翼（再按收起）· K 翻滚 · 深水里自动游泳
- **攀爬**：推着陡坡、树、大石头会爬上去，耗体力；体力见底会松手，累瘫到 35% 才恢复；吃力时冒汗
- **视角**：V 或右下角按钮在“固定俯视”和“自由视角”之间切换；自由视角按住右键拖动旋转、滚轮缩放
- **昼夜 / 天气**：现实 12 分钟 = 一天；晴 → 多云 → 下雨轮换。雨天地面变湿、水洼反光、雨滴溅起水花，路灯自动点亮
- **帐篷**：E 钻进帐篷坐下（布变半透明能看到人），里面挡风挡雨；再按 E 睡觉，移动就出来。自己搭的帐篷门口会生一堆小火
- **烤火 / 烹饪 / 钓鱼**：营火就在营地帐篷门口；烤鱼、烤椰肉、烤蟹钳、烤番薯、椰汁鱼汤；水边有鱼影处按 E 钓鱼
- **耕种**：锄头开垦（营地旁有一块现成的 3×2 田）→ E 播种、Q 换种子 → 水壶浇水（下雨自动浇）→ 按游戏时间长大 → 收获番薯/番茄/西瓜，常会多得种子；灌木丛也会掉种子
- **地图**：约 520 米见方——起始岛、北部风冠山（约 27 米高，山顶有宝箱，适合滑翔）、西部雨林岛与高山湖、东部断崖岛、南方小岛群；瀑布落进水潭，再沿河道流进大海
- **海水**：8 组 Gerstner 波叠加，浪尖按水面挤压程度起沫，岸边是噪声打散的泡沫带
- **存档**：自动存档（每 15 秒 + 关键节点），包含时间、天气、帐篷、田地

## 操作

WASD 移动 · Shift 奔跑 · 空格 跳跃/滑翔 · K 翻滚 · J/左键 攻击 · E 互动 · Tab 背包制作 · F 吃东西 · Q 换种子 · B 搭帐篷 · V 切换视角 · 滚轮缩放 · 右键拖动旋转（自由视角）。
手柄：左摇杆移动 · 右摇杆转镜头（自由视角）· A 跳 · B 翻滚 · X 攻击 · Y 互动 · RT 跑。

| `src/systems.js` | 烤火着凉、烹饪、钓鱼、帐篷（钻进去/睡觉） |

## 和概念文档的差距

- 只有晴帆岛；根潮沼泽、海图、鹦鹉伙伴技、Boss 未做；暴风雨/闪电没做
- 潮汐周期压缩到 75 秒（文档是 6 分钟），方便原型验证
- 配方 11 个（文档切片 12 个）；图标暂用 emoji，正式版需原创图标
- 模型全部代码拼装，没有骨骼动画和表情形态键；用于验证比例、镜头、配色

字体：得意黑 SmileySans（OFL-1.1 开源授权），文件在 `public/fonts/`。

背景音乐：4 首 CC0 电子乐（OpenGameArt），默认 Spring Spring 的《Catchy》。右下角按钮或 N 换歌，M 静音，选择会记住。来源见 `public/music/CREDITS.md`。

## WebGPU 预览（webgpu.html）

标题页底部紫色按钮进入，或直接打开 `/webgpu.html`。用 three.js `WebGPURenderer` + TSL 节点着色器 + compute shader 重写了一版晴帆岛场景（只看画面，不能玩）：

- 海面：128 组按海浪谱采样的 Gerstner 波，每帧在 compute shader 里给 14.7 万个顶点求和（位移、法线、雅可比→浪尖白沫）；可切平静 / 普通 / 风暴
- 雨：8 万颗雨滴在 GPU 上更新
- 草：20 万根，顶点着色器里随风弯曲
- 不支持 WebGPU 的浏览器会自动回退到 WebGL2

代码在 `src/webgpu/main.js`，复用了游戏的地形和模型。
