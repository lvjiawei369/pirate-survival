# 潮汐遗梦 · 3D 海盗生存概念板

打开 `index.html` 即可浏览概念设计板。内容包含：

- 核心玩法支柱与美术方向
- 群岛地图、起始营地、风暴海概念构图
- 道具、食物、敌人与 UI 的视觉语言
- 可按类别筛选的 vertical slice 资源清单
